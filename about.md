# Window Counter

Replays a macro in-game, shifts every input by ±N ticks and records how many ticks each input can move before the player dies. Exports `nandl.json` (format `nandl-calculator`) that the HyperClick trainer imports.

1. Put `macro.json` into this mod's save folder (the mod shows the exact path if it can't find it).
2. Open a level, pause, press **Count**.
3. When it finishes, take `nandl.json` from the same folder.
